# Скриншоти для звіту

Надані користувачем зображення скопійовано без редагування:

- `01_ontograf_full.png` — 6 класів предметної області та 18 індивідів у графі OntoGraf.
- `02_object_properties.png` — список чотирьох Object Properties.
- `03_data_properties.png` — список трьох Data Properties.
- `04_individual_values.png` — ієрархія, процесори та числові значення PSU_650W.

Власне захоплення вікна через Computer Use не працює через помилку `0x80004002`. Ці файли є оригінальними зображеннями від користувача, а не автоматичними захопленнями асистента.

Стан HermiT у GUI та панелі Domain/Range на цих кадрах не показані. Опис кожного кадру наведено у `REPORT.md` у батьківській папці.
