# Практичне заняття 8

Поглиблений структурний, кластерний та семантичний аналіз графа Wikidata. Варіант 12 — географія та адміністративний устрій.

Використано збережений граф практичної 7: 2389 сутностей та 4402 ребра. Копія в `data/geography_graph.json` збігається з вихідним файлом за SHA-256. Первинне джерело — Wikidata через QLever; дата отримання 26.10.2026 збережена в атрибутах графа.

## Результати

- Louvain: 214 спільнот, модульність 0.402260 за resolution=1 і seed=12.
- 1759 міжкластерних ребер; усі використовують P17. Справжніх мостів немає; єдина точка артикуляції — Німеччина Q183.
- Після видалення Q183 утворюється 401 компонента, найбільша має 30 вузлів. Після п'яти видалень за початковим PageRank — 476 компонент, найбільша має 27 вузлів.
- Випадковий контроль: 500 наборів по п'ять різних вузлів. Головний хаб у цих випробуваннях не вибрано. Ймовірність вибрати його в одному наборі дорівнює 5/2389, приблизно 0.2093%; нуль спостережень не означає нульового ризику.
- Діаметр дорівнює 2. Основний его-граф r=2 охоплює всю мережу; додатковий локальний его-граф має 29 вузлів.
- Для відсутньої пари Прюм → P131 → Südeifel знайдено 8 простих шляхів довжини 2–3, з них 3 проходять лише через P131. Ці свідчення характеризують спільне оточення та не встановлюють адміністративну належність як перевірений факт.

## Запуск

Перевірено з Python 3.12.14. Команди виконуються з каталогу `practice8`.

```sh
python -m pip install -r requirements.txt
python structural_analysis.py
```

Інший каталог результатів або запуск без рисунків:

```sh
python structural_analysis.py --output results
python structural_analysis.py --no-plots
```

Ноутбук містить стиснений знімок графа та повний код. Його можна відкрити у Jupyter або Google Colab і виконати згори вниз без додаткової мережевої вибірки.

## Методика

Топологія, PageRank, кластеризація та структурна стійкість досліджуються на простій неорієнтованій проєкції без літералів. Однакове значення resolution застосовується до Louvain та modularity. Центральності всередині спільнот обчислюються на відповідних індукованих підграфах.

П'ять цільових вузлів визначаються один раз за PageRank початкової неорієнтованої мережі. Випадкові видалення відбуваються без повернення в кожному випробуванні. Ізольовані вузли, що виникають після атаки, враховуються як компоненти. Перцентильні смуги показують розкид випадкових результатів.

Предикати й напрямки кроків семантичного шляху відновлюються з оригінального MultiDiGraph. Для передбачення зв'язків точно перелічуються всі прості шляхи з 2 або 3 ребер; довші шляхи не включаються до наведених лічильників. Зв'язки не додаються до початкового графа.

Розбиття порівнюється з типами сутностей і первинними адміністративними групами міст за NMI. Для міста з кількома P131 група визначається найменшим QID як детермінованим правилом порівняння. Воно не визначає правовий чи часовий пріоритет адміністративної одиниці.
